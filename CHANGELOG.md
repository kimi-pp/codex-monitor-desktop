# Changelog

All notable changes to Codex Monitor Desktop are recorded here.

## v0.1.0 - 2026-06-06

- Initial public release.
- Local read-only Codex runtime monitoring.
- Project selector for discovered Codex workspaces.
- Resident-agent scope filtering for the main monitor scene.
- Six-state runtime mapping: working, thinking, blocked, error, idle, offline.
- Animated office scene with workstation, pantry, restroom, treadmill, and walking transitions.
- Windows portable executable release target.
